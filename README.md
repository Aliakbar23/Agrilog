# 🌱 AgriLog

Aplikasi Android untuk mengecek kesehatan tanaman, pohon, dan objek alam lainnya hanya dari foto — didukung AI vision, plus papan harga komoditas real-time untuk wilayah Malang Raya.

## ✨ Fitur

- **Cek Kesehatan Tanaman via Foto** — foto tanaman/pohon yang bermasalah, AI langsung menganalisis dan memberi diagnosis apa yang salah
- **Papan Harga Komoditas** — pantau harga komoditas real-time khusus wilayah Malang Raya, diambil dari sumber data resmi (SISKAPERBAPO & PIHPS Nasional/BI)
- Ringan, cepat, dan mudah digunakan langsung dari HP

## 🛠️ Tech Stack

- React Native (Expo)
- Google Gemini API (Vision)
- Supabase
- Playwright
